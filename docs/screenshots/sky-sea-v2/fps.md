# 프레임 수 (전 / 후)

Playwright + 설치된 Chrome(headless, Metal), 휴대폰 크기 390×844 · 화면 배율 3, `--disable-gpu-vsync --disable-frame-rate-limit` 로 60 제한 없이 5초 평균.
이 Mac(M 시리즈) 기준이라 실제 휴대폰 값은 아님. 같은 조건에서도 실행마다 ±40% 정도 흔들려서 범위로 적음.

| | 바다 (낮/밤) | 둥둥 (낮/밤) |
|---|---|---|
| 전 (dpr 1.75, 블룸 없음) | 534 / 546 | 545 / 527 |
| 후 · 높음 (dpr 1.75, 블룸, MSAA 4) | 256 ~ 271 | 190 ~ 267 |
| 후 · 보통 (dpr 1.5, 블룸 0.35배) — 휴대폰 기본 | 230 ~ 458 | 207 ~ 440 |
| 후 · 낮음 (dpr 1, 블룸 없음) — 저사양 휴대폰 기본 | 471 ~ 590 | 510 ~ 555 |

- 가장 큰 비용은 블룸(빛 번짐). 낮음 단계는 이전보다 빠름.
- 실제 기기에서 4초 평균 40fps 아래가 두 번 이어지면 `FrameGuard` 가 한 단계씩 낮춤.
- 다시 재기: `SUMBI_QUALITY=medium node scripts/capture-skysea.mjs <폴더> <접두어> fps`
