# 바다 친구들 전후 fps (휴대폰 크기)

`node scripts/fps-sea-friends.mjs <폴더> <이름>` — 390×844, dpr 3, 헤드리스 Chrome(vsync 끔, 상한 없음). 수면 · 물속(계속 잠수) · 둥둥 각 몇 초 평균.
수치는 이 맥북에서의 상대 비교용 (실제 휴대폰은 60에 묶임).

| 품질 · 시간 | 수면 전 → 후 | 물속 전 → 후 | 둥둥 전 → 후 |
|---|---|---|---|
| low 낮 | 559 → 556 | 559 → 583 | 526 → 546 |
| low 밤 | 563 → 555 | 519 → 551 | 525 → 551 |
| medium 낮 | 439 → 450 | 382 → 379 | 467 → 481 |
| medium 밤 | 438 → 445 | 383 → 380 | 426 → 438 |
| high 낮 | 260 → 265 | 239 → 240 | 277 → 282 |
| high 밤 | 260 → 265 | 239 → 240 | 252 → 256 |

차이는 잴 때마다 생기는 흔들림 안. 물속 생물은 물속 카메라일 때만, 30m 안에서만 그리고 움직이며,
자리돔은 인스턴스 한 번 그리기(꼬리는 정점 셰이더), 마리 수는 품질 단계에 따라 줄어듦.
