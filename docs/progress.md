## 현재 상태

### 동작하는 것
- 입장 화면에서 랜덤으로 준비된 해녀로 바로 입장, 꾸미기(물수건 8 · 테왁 6 · 볼 4색, 닉네임 36×36), 다음 방문 때 그대로
- 수면 헤엄(WASD/방향키, 카메라 기준), 드래그 시점·휠 줌, 가만히 있으면 카메라 쪽 돌아보기
- 잠수(Space 누르고 있기): 웅크림 → 머리부터 입수(물보라·첨벙) → 머리 아래 하강 → 바닥 근처 엎드려 개구리헤엄 → 떼면 상승 → 퐁 + 숨비소리(3초 이상 잠수 시)
- 숨 게이지 30초, 부족하면 볼 부풂·땀·심장 소리, 0이면 자동 상승
- 해산물(소라·전복·성게) 가까이 가면 자동 채집, 들어 보이기, 망사리(오늘 하루 브라우저 저장)
- 인사(1키 / 버튼), 내 말풍선, 상단 토스트(개발 모드에선 가짜 이웃 행동·멀리서 숨비소리)
- 오늘의 바다 카드(오프라인 흉내), 볼륨 패널(파도·숨비소리·효과음)
- **멀티플레이** (`./dev.sh`): 같은 바다의 다른 해녀가 꾸미기·닉네임 그대로 보이고, 위치는 100ms 버퍼로 보간. 잠수하면 테왁이 수면에 남아 둥둥, 숨비소리는 거리·방향에 따라 작게, 상단 토스트·오늘의 바다는 서버 값
- 백엔드: 방 50명(꽉 차면 새 바다, 빈 바다 정리), 전체 상한 초과 시 대기 화면, 위치 10Hz 묶음 방송, 행동 즉시 방송, 위치 범위·속도 보정, 초당 30개·1KB 제한, 닉네임·색 허용 목록 검증, heartbeat 30초, 재접속 토큰(끊김 20초 유예), 오늘의 바다 **Redis 집계**(KST 날짜 키, 48시간 TTL, Lua 로 원자적, 서버 재시작에도 유지) — Redis 가 없거나 멈추면 메모리로 자동 전환
- 서버에 못 붙으면 혼자 하는 바다(`OfflineNetClient`)로 자동 전환 + 안내 토스트. 연결 중 끊기면 "다시 연결하는 중" 표시 후 자동 재접속(1·2·4…최대 5초, ±30%)
- **동시접속 상한·대기** (운영 처음 20명): 상한에 닿으면 새로 온 사람은 혼자 하는 바다에서 놀면서 대기(구석에 `⏳ 대기 N번째 · 약 N분`, 예상 시간은 최근 입장 간격으로). 자리가 나면 차임 + "🌊 바다에 자리가 났어요" 카드(45초, 탭 제목 깜빡임) → "바다에 들어가기" → 수면 시작 위치로 이동. 놓치면 맨 뒤로. 제안 중 자리도 찬 자리, 새치기 없음. 상한은 Redis `sumbi:config:max-total` 을 5초마다 읽어 **재시작 없이** 바뀜 (`deploy/cap.sh 50`, Actions › Capacity 버튼). `/health` 에 `maxTotal`·`waiting`
- **휴대폰 알림**: 디스코드/텔레그램 웹훅(`SUMBI_ALERT_WEBHOOK_URL`, 비면 끔) — 서버 시작·가득 참·대기 시작·상한 변경, 같은 종류는 10분에 한 번(건너뛴 수를 다음 알림에)
- **무중단 배포**: 서버가 꺼질 때(SIGTERM) 모든 접속에 **1012 (server restart)** → 브라우저는 "바다를 새로 단장하고 있어요" 후 0.3~3초 사이 아무 때나 다시 접속. 꺼지는 중 새로 온 연결도 1012
- **Docker**: `backend/Dockerfile`(arm64·root 아님·prod 프로필), `deploy/` (nginx·blue/green·redis compose, `deploy.sh` 건강 확인 후 전환·실패하면 이전 유지, `local.sh` 로컬 확인). GitHub Actions: push 마다 테스트·빌드·린트, main 이면 arm64 이미지 → GHCR, 배포·상한은 버튼(OIDC → SSM). Vercel 미리보기는 서버에 붙지 않음(`VITE_VERCEL_ENV`)
- 서버 전송 동시성: 연결마다 보낼 줄 + 전송 스레드 하나, 느린 연결(전송 3초 초과·256KB 초과)만 정리, 동시 입장·퇴장에도 방 인원·배정 정확 (2026-11-03 점검)
- **불턱** (수면에서 "불턱으로"): 페이드 후 둥근 돌담 안 빈자리에 자동으로 앉아 불 쬐기, 모닥불 타닥 소리(가까울수록 크게). 내가 딴 것만 손질(소라 두드리기·전복 떼기·성게 알 맛보기, 키 2/3/4), 공동 대야가 차고 가득 차면 불턱 해녀 모두 만세 → 다음 대야(인원×4, 12~40). 귤 까먹기(T)·꾸벅꾸벅 졸기(Z, zzz). 다른 사람 손질은 같은 모션 + 토스트. 바다로 버튼으로 해안 앞 수면 복귀
- **불턱 자리 옮기기**: 빈 방석 돌에 마우스를 올리면 은은하게 빛나고 손가락 커서(찬 자리·누가 가는 자리는 반응 없음), 누르면(휴대폰은 탭) 서버 승인 뒤 일어나 기지개 → 돌기 → 테왁을 옆구리에 끼고 뒤뚱뒤뚱 모닥불 둘레로 → 불 쪽으로 돌기 → 콩 뛰었다 털썩(먼지·반짝·퐁 소리) → 다시 불 쬐기. 걷다가 다른 자리를 누르면 방향을 바꿈. 같은 자리를 둘이 동시에 누르면 먼저 온 한 명만, 다른 한 명은 그 자리를 보며 "앗". 다른 사람 화면에도 같은 길·같은 걸음으로 (위치는 안 보냄). 24자리가 다 차면 담 밖에 서서 불 쬐기 → 자리가 나면 눌러서 입구로 들어옴
- **실제 시간 바다**: 한국 시간을 따라 새벽·낮·노을·밤 (하늘 그라데이션, 해·달·별, 빛 색·방향, 물빛, 물속 안개·빛줄기). 밤엔 수면에 달빛 길, 물속에 푸른 플랑크톤이 가물거리고 헤엄치면 지나간 자리에 빛이 흩어짐. 시간대 사이는 부드럽게 섞이고, 고정 시각을 바꾸면 몇 초에 걸쳐 그 사이 시간을 지나감. 개발용: `?time=dawn|day|sunset|night`, `?hour=21.5`, 콘솔 `__sumbi.setTime('night')` / `setTime(null)`
- **둥둥** (☁️ 버튼 / F, 바다 수면에서만): 테왁을 배에 안고 누워 하늘 보기. 파도 따라 흔들리며 아주 느리게 떠내려가고, 가끔 눈 감기·하품·테왁 고쳐 안기·발끝 까딱. 카메라는 수면 가까이에서 하늘을 올려다보고(끌기·휠로 둘러보기, 멈추면 기본 구도로), 몇 초 뒤 UI가 사라져 하늘만 + "일어나기"만 은은하게. 하늘은 실제 시간: 낮 구름·갈매기(끼룩), 노을 주황→보라·구름 아랫면 물듦, 밤 별 2,400개·은하수·달·가끔 별똥별("별똥별이 떨어졌어요"), 새벽엔 별이 하나씩 사라짐. 귀가 물에 잠긴 소리. 이동 키나 일어나기로 몸을 뒤집어 복귀. 다른 사람에겐 누운 해녀 + 가끔 ☁️/✨. 일지에 "하늘을 N분 바라봤어요"·"별똥별을 봤어요". 구름은 평소 하늘에도 있음
- **하늘·바다 v2**: 하늘은 산란 흉내 그라데이션·해 둘레 빛·수평선 안개, 크기·높이가 다른 뭉게구름(해 쪽 밝고 아랫면 그늘, 은빛 가장자리), 밤엔 등급·색이 다른 별 4,800개(밝은 별은 작은 빛무리)·먼지띠가 있는 은하수·실제 날짜 위상의 달과 달무리, 새벽엔 수평선 별부터 사라지고 동쪽이 분홍·하늘색. 바다는 잔물결 노멀맵 여러 겹·프레넬 하늘 반사(하늘과 같은 식)·햇빛 반짝임·노을빛 길·달빛 길, 해안 가까이 옥빛 → 먼바다 짙은 파랑, 해안 포말·밀려갔다 빠지는 물결, 먼 흰 파도. 해안은 구멍 숭숭 현무암, 물에 닿는 띠는 젖어서 어둡고 반짝임, 먼 산은 푸르스름하게 뿌옇게. 물속은 깊을수록 빨강부터 빠지는 색, 떠다니는 입자, 모래 물결 무늬, 올려다보면 수면 너머 하늘이 일렁임. 다른 해녀·테왁도 내 화면의 같은 파도 높이에, 수면 해녀 둘레 동그란 물결. 톤 매핑(Neutral) + 은은한 블룸(모닥불·해·달)
- **휴대폰 조작** (터치 화면 자동 감지, `?touch=1|0` 으로 강제): 왼쪽 아래 어디든 엄지를 대면 그 자리에 조이스틱(끌어 헤엄, 물속에서도), 오른쪽 아래 세로 버튼(맨 아래 큰 🤿 잠수: **톡 누르면 계속 잠수 → "⬆️ 올라가기"로 바뀌고 다시 톡 하면 올라감**, 누르고 있다 떼는 방식도 그대로 · 숨이 다하거나 수면에 오르면 풀림, 둥둥·인사·불턱), 나머지 화면을 끌어 둘러보기, **두 손가락으로 벌리고 좁혀 줌**(둥둥에선 하늘 시야) — 손가락 두 개 동시 가능. 잠수 중 숨 게이지는 위쪽(오늘의 바다 밑). 망사리 밑에 오늘의 바다(접힌 채 시작)·불턱에선 공동 대야, 물질 마치기는 📔 아이콘, 키 안내 숨김·터치용 안내 문구. 가로 화면은 안내 문구를 맨 위 가운데로. 게임 화면에서 끌기·두 손가락은 페이지 스크롤·확대로 넘어가지 않음
- **휴대폰 개발 확인**: `./dev.sh` 가 프론트를 `--host` 로 열고 내부 IP 를 허용 origin 에 더한 뒤 휴대폰 주소를 찍어 줌. `?debug=1` 이면 오른쪽에 fps·가장 긴 프레임·품질 단계·dpr (개발 서버에서만)
- **품질 단계** (`lib/quality.ts`): 높음·보통·낮음 — 해상도 배율·구름 수·잔물결 겹 수·블룸(낮음은 끔)·그림자 크기. 기기로 짐작(휴대폰은 보통, 저사양 휴대폰은 낮음), 4초 평균 40fps 아래가 두 번 이어지면 한 단계 낮춤. 개발용: `?quality=high|medium|low`, `?moon=0.5`(달 위상), 콘솔 `__sumbi.quality.getState().set('low')`
- **물질 일지** (상단 "📔 물질 마치기"): 이번 물질 기록(머문 시간·숨비소리·딴 것·손질한 것·함께한 해녀) + 내 해녀를 앞에서 찍은 지금 시간대 풍경으로 1080×1350 카드. "오늘 바다에 23분 머물렀어요" 같은 문장과 시간대별 마무리 한 줄. 이미지로 저장(휴대폰은 공유 시트, 그 밖엔 내려받기), 계속 물질하기 / 바다 떠나기(입장 화면, 다시 들어오면 새 물질). 기록은 브라우저에만 (`sumbi.journal`, 최근 60개, 탭을 닫아도 남김)
- **바다 친구들** (잡을 수 없음, 반응만): 물속에서 자리돔 떼(다가가면 흩어졌다 다시 모임), 잠수를 시작하면 가끔 따라오다 떠나는 노란 물고기, 오므렸다 쭉 나아가는 한치, 바위 틈에서 빼꼼하다 다가가면 "쏙" 숨는 문어, 옆으로 걷다 도망가는 게, 껍데기로 숨는 소라게, 불가사리, 깊은 곳 해파리(밤엔 은은하게 빛남). 마리 수는 품질 단계를 따르고 물속 카메라일 때 30m 안만 그림. **바다거북**: 바다에 4~10분 머물면 한 번쯤 물속에서 눈앞을 지나감 → 머리 위 "!" + 일지 "바다거북을 만났어요" (내 화면에만). **남방큰돌고래**: 바다마다 평균 30분(8~90분)에 한 번, 물질하는 곳에서 15~22m 바다 쪽을 3~6마리가 뛰어오르며 지나감(물보라·멀리서 돌고래 소리). 같은 바다의 모두가 같은 순간에 같은 장면, 늦게 들어와도 남은 장면. 토스트 "돌고래가 지나가요!", 일지 "남방큰돌고래를 봤어요"(하루 한 번), 오늘의 바다 "🐬 오늘 돌고래가 N번". 개발용 `?event=dolphin|turtle`, 콘솔 `__sumbi.dolphin()`·`turtle()`·`friends` (운영 빌드·prod 서버에선 꺼짐)
- 테스트: 바다 친구들 Playwright 20개 항목 (`capture-sea-friends.mjs`, 브라우저 3개), 백엔드 91개(돌고래 일정·방송·늦게 온 사람·오늘 집계·개발용 호출 포함), 둥둥 Playwright 30개 항목 (`capture-dungdung.mjs`, 브라우저 2개 + 시간대 4개 + 모바일), 백엔드 67개(+ 자리 옮기기 8개: 16명 동시 요청 50회 포함), 불턱 자리 옮기기 Playwright 28개 항목 (`capture-bulteok-seat.mjs`, 브라우저 4개 + 가짜 해녀 21명), 이전: 백엔드 59개(단위 + 동시성 + 불턱 + Redis(실제 redis-server, 없으면 건너뜀) + WebSocket 통합), 프론트 멀티플레이 Playwright 14개 항목 (`capture-multiplayer.mjs`), 불턱 17개 항목 (`capture-bulteok.mjs`), 시간대 9개 항목 (`capture-time.mjs`), 물질 일지 11개 항목 (`capture-journal.mjs`)

### 미완성 작업
- 없음. 모든 작업이 `main` 에 있고 실행 가능 (타입 검사·lint·빌드·백엔드 테스트·Playwright 캡처 통과).
- 확인만 남은 것: 하늘·바다 v2 느낌 피드백, 실제 휴대폰 확인(프레임 수는 이 Mac 의 모바일 흉내 값뿐 — `docs/screenshots/sky-sea-v2/fps.md`).

### 알려진 문제
- 하늘·바다 v2 는 블룸이 가장 무거움: 이 Mac 모바일 흉내에서 프레임이 이전의 약 절반(보통 단계). 실제 휴대폰에서 40fps 아래면 자동으로 낮음(블룸 끔)으로 내려가지만 아직 기기로 확인 안 함
- 물에 비친 하늘은 하늘 색 식만 반사 (구름·산은 반사 안 됨)
- `capture-journal.mjs` 의 "함께한 해녀" 항목은 같은 백엔드에 다른 브라우저(사용자 Chrome 등)가 붙어 있으면 숫자가 달라 실패로 나옴 — 코드 문제 아님
- 둥둥: 별똥별·갈매기는 내 화면에만 (다른 사람과 같은 하늘을 보지는 않음). 구름은 모두 같은 시각에 같은 자리지만 내 둘레를 감싸 돌므로 멀리 떨어진 두 사람은 다른 구름을 봄
- 하강 시작 순간 카메라가 수면을 통과하는 0.1초 정도 어색한 프레임
- 빌드 시 청크 500KB 초과 경고 (three.js). 5단계에서 코드 분할 검토
- oxlint `react(immutability)` 경고 다수 (R3F에서 three 객체를 직접 바꾸는 패턴). 의도된 것
- 휴대폰 조작은 Chrome 터치 흉내로 확인. 실제 iPhone(카카오톡 인앱 브라우저)에서 둘러보기가 안 되던 문제는 iOS 스크롤 막기로 고쳤지만 기기에서 다시 확인 필요.
- 다른 해녀 LOD 없음 (50명이면 메시 약 1,150개) → 사람이 많을 때 성능 확인 필요
- 부하 테스트(가짜 클라이언트 50~200명) 아직 안 함. 운영 상한은 20명에서 시작(`application-prod.yml`), 개발 기본 500. 올리기 전에 k6 로 확인
- 대기 중에 서버 연결이 끊겼다 다시 붙으면 대기열 맨 뒤로 감. 대기 중 혼자 바다에서 딴 해산물은 서버 손질 장부(`PrepLedger`)에 없음 (불턱에서 손질 못 함)
- 배포(1012 → 다시 접속)하면 새 서버에선 새 해녀 번호·수면 시작 위치로 다시 들어감 (방·재접속 정보는 서버 메모리). 불턱에 있었으면 바다로
- GitHub Actions 워크플로(배포·상한 버튼)는 AWS 가 없어 아직 실제로 돌려 보지 않음 (YAML·셸 문법·로컬 `deploy.sh`/`cap.sh` 만 확인). 2단계 첫 배포 때 확인
- 서버를 재시작하면 방·재접속 정보가 사라져 새 번호로 다시 입장 (오늘의 바다는 Redis 에 남음). 불턱 손질 장부(`PrepLedger`)도 메모리라 재시작하면 손질 가능 개수가 0
- Redis 가 멈춘 사이 메모리로 센 값은 Redis 가 돌아와도 합쳐지지 않음 (그 사이 채집이 오늘의 바다에서 빠짐)
- 같은 브라우저의 탭 두 개는 저장소(토큰)를 같이 써서 오늘의 바다에서 한 명으로 셈
- 불턱 해녀가 많아 담 밖 자리(24번~)에 서면 바닥 높이를 지형에서 가져와 돌담 바깥 경사에 따라 어색할 수 있음 (24명 넘게는 아직 확인 안 함)
- 담 밖에 서 있는 해녀(24번~)는 돌담보다 낮은 지형에 서서 화면에서 불턱 바닥보다 아래로 보임. 입구로 들어올 때 높이는 담 근처에서 부드럽게 섞음
- 다른 해녀의 걸음은 `seat` 를 받은 순간부터 재생하므로 그 사람 화면보다 지연(보통 수십 ms)만큼 늦게 앉음. 걷는 중 새로 들어온 사람은 그 해녀가 이미 목적지에 앉은 모습으로 봄
- 바다 친구들: 바다거북·따라오는 물고기·문어 빼꼼은 내 화면에만 (다른 사람과 같은 장면 아님). 돌고래만 같은 바다가 함께
- 둥둥 카메라는 돌고래 쪽으로 저절로 돌지 않음 (소리·토스트를 듣고 끌어 둘러봐야 함)
- 돌고래 일정은 서버 메모리 — 서버를 재시작(배포)하면 바다마다 새로 한 간격 뒤부터
- 물질 일지 사진은 WebGL 캔버스를 바로 읽으므로, 그 순간 그래픽 컨텍스트를 잃었으면 사진 없이 색 그라데이션 카드로 나옴
