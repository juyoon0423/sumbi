# 소리 파일 넣는 곳

이 폴더에 아래 이름으로 파일을 넣으면, 합성음 대신 그 파일이 자동으로 재생됩니다.
파일이 없으면 브라우저에서 만든 임시 합성음이 나옵니다. 코드는 고칠 필요가 없습니다.

| 파일 이름 | 용도 | 비고 |
|---|---|---|
| `sumbi.mp3` | 숨비소리 "호오이~" | 1~2초 길이 권장. 앞뒤 무음은 잘라 주세요 |
| `sumbi-2.mp3`, `sumbi-3.mp3` | 숨비소리 변형 (선택) | 있으면 무작위로 섞어 재생 |
| `waves.mp3` | 파도 소리 (반복 재생) | 끝과 처음이 자연스럽게 이어지는 루프 |
| `splash.mp3` | 입수 소리 | |
| `harvest.mp3` | 채집 소리 | |

- 사람마다 숨비소리 음높이를 조금씩 다르게 들리도록 재생 속도를 바꿔 재생합니다.
- 다른 형식(.ogg, .wav)을 쓰려면 `src/audio/AudioEngine.ts`의 `FILES` 목록을 수정하세요.
